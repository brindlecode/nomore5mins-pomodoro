# NoMore5Mins Pomodoro — Remotion Edition

Pomodoro timer video generator for the NoMore5Mins YouTube channel.  
**2448 videos** × Remotion (React-based) with smooth 30fps animations.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Generate signal sound files (one-time)
npx tsx scripts/generate-tones.ts

# 3. Add your music files
#    Copy .mp3 files to public/break_music/
#    Required: default.mp3, lofi.mp3, rain.mp3, piano.mp3, nature.mp3, ocean.mp3

# 4. Add your logo
#    Place logo.png in public/

# 5. Open Remotion Studio to preview
npm start

# 6. Test render a single video
npm run test:sprint

# 7. Test render a thumbnail
npm run test:thumb
```

## Video Catalog (2448 Videos)

### 9 Pomodoro Configs
| Config | Focus | Break | Badge |
|--------|-------|-------|-------|
| 15-3   | 15m   | 3m    | ADHD-Friendly |
| 20-4   | 20m   | 4m    | Quick Focus |
| 25-5   | 25m   | 5m    | Classic |
| 30-10  | 30m   | 10m   | Extended |
| 40-10  | 40m   | 10m   | Deep Study |
| 45-15  | 45m   | 15m   | Pro Block |
| 50-10  | 50m   | 10m   | Power Mode |
| 52-17  | 52m   | 17m   | Science-Backed |
| 90-20  | 90m   | 20m   | Deep Work |

### Modes
- **Sprint:** 1x, 2x, 3x, 4x, 5x, 6x, 8x, 10x (no break after last focus)
- **Cycle:** 1, 2, 3 cycles × 15/20/30m long breaks (4 pomodoros per cycle)

### Audio × Theme = 18 Variants per video
- **3 Audio Modes:** Silent, Music, Ambient
- **6 Music Themes:** Calm, Lo-Fi, Rain, Piano, Nature, Ocean

## Rendering Commands

### Studio Preview
```bash
npm start
# Opens http://localhost:3000 — preview any composition with props
```

### Single Video
```bash
# Sprint: 2×25/5 with piano music, silent mode
npx remotion render PomodoroVideo out/test.mp4 \
  --props='{"config":"25-5","mode":"sprint","sprint":2,"audioMode":"silent","theme":"piano"}'

# Cycle: 1 cycle, 15m long break
npx remotion render PomodoroVideo out/test_cycle.mp4 \
  --props='{"config":"25-5","mode":"cycle","cycles":1,"longBreak":15,"audioMode":"silent","theme":"default"}'
```

### Single Thumbnail
```bash
npx remotion still Thumbnail out/thumb.png \
  --props='{"config":"25-5","mode":"sprint","sprint":2,"audioMode":"silent","theme":"piano"}'
```

### Batch Rendering
```bash
# Show batch plan (no rendering)
npx tsx scripts/render.ts --batch-plan

# Render batch 1 (50 videos + thumbnails)
npx tsx scripts/render.ts --batch 1

# Render batch with custom size
npx tsx scripts/render.ts --batch 1 --batch-size 25

# Dry run (show what would be rendered)
npx tsx scripts/render.ts --batch 1 --dry-run

# Filter by config/mode/theme
npx tsx scripts/render.ts --config 25-5 --mode sprint --theme piano
```

### Thumbnails Only (Fast)
```bash
npx tsx scripts/render-thumbnail.ts
npx tsx scripts/render-thumbnail.ts --batch 1
npx tsx scripts/render-thumbnail.ts --config 25-5
```

### YouTube Metadata
```bash
# Generate all metadata
npx tsx scripts/generate-metadata.ts

# Show catalog count
npx tsx scripts/generate-metadata.ts --list

# Batch metadata
npx tsx scripts/generate-metadata.ts --batch 1
```

## Filename Convention

### Sprint
- `pomodoro_25-5` → 1x sprint, silent, default theme
- `pomodoro_2x25-5` → 2x sprint
- `pomodoro_2x25-5_music` → music audio mode
- `pomodoro_2x25-5_music_lofi` → music + lofi theme
- `pomodoro_2x25-5_ambient_rain` → ambient + rain

### Cycle
- `pomodoro_cycle1x25-5_lb15` → 1 cycle, 15m long break, silent, default
- `pomodoro_cycle2x25-5_lb30_music_piano` → 2 cycles, 30m LB, music, piano

## Technical Notes

- **FPS:** 30 (smooth animations vs Python's 1 FPS)
- **Resolution:** 1920×1080 (video), 1280×720 (thumbnail)
- **YouTube limit:** Max 43,199 seconds (just under 12 hours)
- **Audio:** Bell (528Hz singing bowl), Chime (396Hz), Gong (174Hz), Beeps (880/1046Hz)
- **Music:** Auto-loop with crossfade handled by Remotion's Audio component
- **Seeded random:** Same config always produces same motivational phrases
